# Python Practice

Exercises and small projects from my Python courses.

## Contents
- `01-basics`: conditions, while/for loops, strings, multiplication table, averages
- `02-loops-patterns`: star and number patterns with nested loops, series
- `03-functions`: functions, `*args` / `**kwargs`, validation exercises
- `04-lists`: list operations, scores, counting, common elements, iterators
- `05-number-problems`: divisors, prime and perfect numbers, factorial, Fibonacci
- `06-datetime`: formatting dates with `strftime`
- `07-strings`: `replace`, `translate`
- `08-dicts-and-random`: dictionaries, BMI, `random`
- `09-games`: rock-paper-scissors
- `10-gui-tkinter`: console calculator, GUI calculator, digital clock, paint app (tkinter)
- `11-file-handling`: reading text files

## Projects
- `projects/contacts-manager`: command-line phone book saved in a text file
- `projects/course-selection`: course registration system with classes and JSON storage
- `projects/library-csv`: book manager using CSV files
- `projects/store-xml`: product manager using XML files
- `projects/subtitle-translator`: translate `.srt` subtitles to Persian
- `projects/crypto-price-tracker`: log crypto prices from an API into a CSV file

## Setup
Some projects need extra packages:
```bash
pip install -r requirements.txt
```
