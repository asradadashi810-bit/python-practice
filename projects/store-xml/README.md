# Store Manager (XML)

Command-line product manager that stores data in `store.xml`.

## Features
- Show all products (formatted table)
- Search by product name
- Show low-stock products (count < 5)
- Add / remove / edit a product

## Concepts used
`xml.etree.ElementTree`, file handling, functions, `tabulate`.

## Run
```bash
pip install tabulate
python store.py
```
