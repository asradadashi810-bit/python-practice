# Library Manager (CSV)

Command-line book manager that stores data in `books.csv`.

## Features
- Show all books (formatted table)
- Search by title and author
- Books with low stock
- Top 3 books by number of copies
- Add / remove / edit a book

## Concepts used
`csv` module, file handling, functions, `lambda`, `tabulate`.

## Run
```bash
pip install tabulate
python library.py
```
