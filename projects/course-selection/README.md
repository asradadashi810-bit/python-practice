# Course Selection System

A command-line course registration system written with Python classes (OOP).

## Features
- Show all available courses
- Select / remove a course (maximum 20 units)
- Show selected courses and total units
- Search courses by name
- Sort courses by units
- Save and load the student's selection with a JSON file (`data.json`)

## Concepts used
Classes (`Course`, `Student`, `CourseSystem`), lists, `json`, file handling, `lambda`.

## Run
```bash
python course_selection.py
```
